# 正式差异页面接入

2026-11-06，基于 `main@f781946` 接入，随 0.1.18 发布。本次把已确认的原型接到浏览器和 VS Code 共用页面，没有改动解析、记录对齐、差异计算或 CLI 输入方向。本文记录接入与试用验证，发布状态以 GitHub Releases 和扩展市场为准。

## 正式行为

- 页首区分旧、新文件；“来源与设置”可展开完整路径、快照与 XLSX 读取范围，以及格式、主键和外观。交换、重新计算/读取、文本对比和结束比较保留原有宿主行为。
- 默认 Material + 精密矩阵。组件风格 GitHub / Material / Soft UI / Neo Brutalist 与矩阵 / 纸面 / 焦点 / 终端布局独立；选择布局不切换原表/清单，恢复偏好也不覆盖视图。两种视图均支持布局：原表的纸面增加行距、列宽与记录标题层次，焦点将旧新值并排并标识当前行，终端使用紧凑间距与等宽数据。浏览器使用五套已确认的浅深配色，编辑器继续使用自身颜色。
- 组件风格切换只更新 CSS 属性，不重建数据 DOM；切换布局或原表/清单时保留当前记录。原表中换布局保留同一表格、页码与选中记录，行高变化时允许浏览器调整滚动锚点；清单仅在进入/离开焦点时重排。外观设置不发起比较请求，在途筛选完成后才应用所需重排。清单焦点布局只有一份详情；窄屏使用横向队列和内容区统一纵向滚动。
- 当前表统计与筛选结果数分开显示。字段结构变化按实际类型汇总，仍可展开查看。新增按字段筛选，明确不同于原有“仅看变动字段”的列并集；所选字段两侧均不存在的记录不算命中。
- 字段筛选在 Go / JS 的完整模型上、分页前执行。原生页面只接收当前页值与字段名称目录；仍受原有每页记录/单元格限制。上一条、下一条可跨页定位，编号保持原表顺序。定位不产生审查结论。
- 空结果可清除筛选并返回搜索焦点；中文输入法组合期间不提交半成品查询。搜索请求期间保持输入框可用。设置可用 Esc 或外部点击关闭。

## 实现边界

共享模板、渲染及组件 CSS 位于 `src/page.js`、`media/main.js`、`media/main.css`。浏览器配色和外观持久化仍在 `media/themes.*`；Go `preferences` 扩展为 mode / palette / style / layout，兼容旧配置和旧两字段请求。显式非法值、null 和未知字段继续拒绝。编辑器不引入 HTTP 偏好请求或原生 CLI 依赖。

展示投影仅增加 `view.field` 与原生 `filterFields` 名称目录；`media/view.js` 与 `cli/native_table.go` 保持相同筛选规则。原型组件试样、颜色说明、演示状态与固定数据没有进入产品页面。没有新增依赖或生成资源文件种类。

## 验证

- `npm run check`、104 项 Node 测试与 Go `go test -race ./... -count=1` 通过。
- `test:native` 的 24 组 CSV/XLSX 原生/JS 等价场景通过；Go 的投影差分测试增加指定字段、缺失字段和跨页范围。
- `test:ui` 和 `test:browser` 共用新的 `review-interactions.cjs`，验证四种组件处理确实不同、同一表格 DOM 保留、四种风格下纸面行高增加/终端行高减少/焦点旧新并排、字段全表筛选、跨页定位、焦点详情不因文本点击重建、空结果恢复焦点、Esc/外点关闭、390/728/1280px 原表与清单布局以及会话结束后的清理。浏览器回归中的外观偏好通过请求模拟隔离，不写入用户配置。
- `test:themes` 验证五配色浅深文字对比度、系统切换、跨端口/刷新恢复、保存失败、首次比较在途时恢复布局，以及保存的原表视图不被晚到的偏好覆盖。
- 实际截图复核修正了编辑器深色回退选中色、队列按钮被压缩和窄屏详情双层滚动。桌面矩阵表格起点约从原方案记录的 y=386 提前到 y=300 附近；具体位置随主题、窗口及字段变化而不同。
- Hallmark 源码扫描无 FAIL/WARN；纯白宿主色与紧凑组件间距的两类 REFLEX 有明确保留依据。扫描的独立渲染阶段没有 HTML 输入；实际视觉检查采用上述页面测试生成的截图。Impeccable 的单条静态提示把 Material 下划线页签当作圆角卡片；该页签实际为直角且样式来自已确认设计，保留底线。

接入试用阶段已重建五平台 CLI 并同步到 Design 仓库的 `gridiff/`（当时版本为 0.1.17，构建记录标记 sourceDirty）。通过 Design 实际启动器核对构建指纹、页面资源及布局切换；样本矩阵/纸面/终端行高约为 86/122/67px，焦点旧新并排，外观切换未产生比较请求。该试用阶段未提交、推送、发布或更新已安装技能/扩展。浏览器验收基于本机 Chrome，编辑器验收使用真实 Webview 模板与 CSP 的宿主模拟；未在已安装 VS Code 实例、Windows/Linux、完整读屏或全部风格×布局×配色组合上实测。长文本仍沿用原有共同前后缀标记算法，本次没有将其替换为精确全文 diff。

试用反馈修正：阅读布局与原表/清单完全独立，两种视图均有对应布局表现；回归覆盖第二页布局切换不重置滚动、异步偏好恢复，以及第二页搜索在途切换焦点布局时不恢复旧页码。Design 试用需从 Fork 重新发起比较，已有页面仍由旧进程提供资源。
