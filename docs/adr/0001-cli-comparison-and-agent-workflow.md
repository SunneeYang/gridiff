# CLI 提供比较结果，技能组织 agent 工作流

Gridiff 当前命令面向人工审阅输出网页地址，但 Go 核心已具备独立比较能力。面向 agent 的机器输出直接复用该核心，技能负责准备输入、调用与解释；Git 场景由 agent 获取版本文件后交给 Gridiff，以便不同调用者共用同一套表格比较语义。机器输出不依赖网页会话，现有网页入口继续用于人工审阅。

完整比较报告可写入指定文件，由 agent 使用文件工具按需读取，避免为大量差异另建查询服务或沿用网页分页结果。比较参数通过 CLI 公开，技能与同版本可执行程序一起交付，使安装技能即可获得比较能力。

日常技能调用使用 `--temp-output`，临时路径由 CLI 在平台用户缓存目录统一分配，按生成时间保留 72 小时，后续临时调用回收带归属标记的过期项；这使不同会话和异常中断的结果都有统一回收入口。用户要求留档时使用 `--output`，不参与自动过期。
