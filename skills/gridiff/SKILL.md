# Gridiff 表格比较

使用技能包内的 CLI 计算差异，再结合项目代码和约定解释变化。

## 调用

本文件所在目录是技能根目录。通过绝对路径调用其中的 `bin/gridiff`；Windows 使用 `bin/gridiff.exe`。发布包已包含对应平台的程序，无需运行时或全局 PATH。若目录缺少程序，说明拿到的是技能源码，应安装对应平台的完整技能包。

先用包内程序的 `--help` 查参数，再执行：

```sh
"<技能根目录>/bin/gridiff" --output "<报告目录>/diff.json" "<旧版本.csv>" "<新版本.csv>"
```

- 旧版本在前，新版本在后。每次比较使用独立报告路径，先检查退出状态，再读取报告。
- XLSX 默认只比较工作簿顺序中的首表，包含隐藏首表。需要扩大范围时显式使用 `--sheets all` 或可重复的 `--sheet`，在结论中说明实际范围。
- 格式、主键和自定义表头通过 CLI 参数指定。依据项目说明、代码或用户要求调整参数，核对报告中的实际格式、主键和对齐方式。
- 报告保存所选范围内的全部记录与字段，包含未变化记录。大量差异可先读文件开头的统计，再分段读详情；只读取一部分时，结论也限于已核查部分。
- 使用任务专属目录保存快照和报告。报告必须在后续文件读取时仍存在；若命令执行器会回收临时目录，将报告放在其回收范围之外。

## Git 变更审查

用户要求审查配置改动时，主动比较指定范围内的 CSV/XLSX。准备输入前读取 [Git 范围与快照](references/git.md)，按对应基线收集全部相关文件；记录成功、失败和跳过项。

## 解读结果

读取 [报告约定](references/report.md)，按记录标识和字段名关联旧、新值，区分新增、删除、修改、结构与顺序变化。用代码或项目规则支持业务解释，区分工具给出的差异事实与推断。

比较成功需要退出码为零且报告 `complete: true`。失败时读取诊断，修正有依据的参数或报告受阻原因；部分表成功也不代表全部范围已检查。报告写入失败时，已有同名文件可能是旧报告。

完成后给出实际比较范围、主要变化和问题的来源记录/字段；清理本次创建且已不再需要的输入快照。报告按任务需要保留，源表格只读。
